## 🦋 Overview

**FarmShield** is an intelligent farm-security platform combining IoT sensors, artificial intelligence, and real-time monitoring to protect agricultural environments.

Designed to address threats such as theft, water diversion, and unauthorized intrusion, the system monitors critical farm areas, including storage facilities, irrigation infrastructure, and surrounding perimeters.

Through automated detection, remote mobile control, and local protection mechanisms, FarmShield aims to secure agricultural environments even when internet connectivity is unavailable.

## 🦋 Key Features

- **Real-Time Monitoring:** Sensor-based monitoring of farm infrastructure and surrounding activity.
- **AI-Powered Detection:** A three-model AI cascade for human/animal classification, dangerous-animal detection, and facial recognition.
- **Insider Threat Detection:** Isolation Forest-based anomaly detection to identify suspicious activity and potential theft.
- **Automated Response:** Automatic actions such as siren activation and irrigation-valve control.
- **Remote Management:** Mobile application for monitoring and controlling the system.
- **Offline Protection:** Local security mechanisms designed to operate without internet connectivity.
- **Instant Notifications:** Mobile alerts for detected security events, targeting a response time under 5 seconds.

## 🦋 System Workflow

1. **Collect** — ESP32 devices gather information from connected sensors.
2. **Transmit** — MQTT handles communication between devices and the backend.
3. **Analyze** — AI models and anomaly detection mechanisms evaluate incoming events.
4. **Respond** — The system triggers appropriate actions, such as activating a siren or controlling a valve.
5. **Notify** — Security alerts are sent to the mobile application.
